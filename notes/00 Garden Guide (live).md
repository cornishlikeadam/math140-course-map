## 🔢 How to use it
1. **Scroll** the box below. Everything starts **closed**. Tap to open.
2. **Type** a question in **"Ask the Guide"**.
3. **Click** a question card to **see the answer**.
4. **Open** a note link. It opens the note on GitHub.

<iframe src="https://math140-course-map.vercel.app/guide/" width="100%" height="900" title="Garden Guide"></iframe>

> [!NOTE]
> 🌐 The box needs the internet. No internet? Open the notes in this folder instead.

## 🔄 How the site gets new notes
1. **Edit** a note here in Obsidian.
2. **Open** Terminal.
3. **Run** this command:
```bash
cd ~/Documents/math140-course-map && ./scripts/sync-notes.sh
```
4. **Wait** about 1 minute. The site and GitHub now show your change.

> [!IMPORTANT]
> 🤖 The Guide does **not** use AI. It finds answers in **our own notes**. So it is **safe**, and the answers are **ours**.
