# ⚖️ Two Ways to Build It

🧪 **Build pages:** [0 How it works](00%20How%20the%20Build%20Works.md) · [1 PRD](01%20PRD%20-%20What%20We%27re%20Making.md) · [2 ARD](02%20ARD%20-%20How%20the%20Pieces%20Fit.md) · [3 Checklist](03%20Prep%20Checklist.md) · [4 Handoff](04%20Build%20Handoff.md) · [5 Tests](05%20Tests%20and%20Decisions.md) · [6 Two ways](06%20Two%20Ways%20to%20Build%20It.md)

The build pack says: **compare 2 designs.** Pick the best one **for the people**. Do not pick the easiest one.

## 🅰️ Design A: paper hint cards 🃏
1. The teacher prints 1 hint card for each common mistake.
2. The student finds the matching card.
3. The student writes Makes sense / Not sure / I disagree on a sticky note.

## 🅱️ Design B: a clickable practice page 🖱️ ✅ **(picked)**
1. The page shows the hint.
2. The page **does not let you go on** until you decide and give a reason.
3. The page sends unsure hints to the teacher's list.

## 📊 Side by side
| Question | 🅰️ Paper cards | 🅱️ Clickable page |
|---|---|---|
| Works with no computer? | ✅ Yes | ❌ No. So it **keeps the paper rule list**. |
| Makes the student decide? | ⚠️ The sticky note is easy to skip. | ✅ Done stays locked. |
| Teacher sees unsure hints? | ⚠️ Only if the note is given in | ✅ They go to the teacher's list. |
| Can we test the rules? | ⚠️ Hard to test the same way twice | ✅ Same test, same result |
| Shows real AI behavior? | ❌ No | ✅ Closer. Still pretend. |
| Data can leak? | ✅ No | ✅ No. Pretend hints. Nothing saved. |
| Fair with no computer? | ✅ Yes | ✅ Yes. The rule list counts the same. |

## 🏆 Why we picked B
1. It **forces** the most important rule: **the student decides.** Unsure hints **reach the teacher.**
2. It keeps the best part of A: the **no-AI rule list**.

## ⚠️ What we gave up
1. B needs a device.
2. We did not test B with a screen reader.
