# 📨 Build Handoff (What We Told the AI)

🧪 **Build pages:** [0 How it works](00%20How%20the%20Build%20Works.md) · [1 PRD](01%20PRD%20-%20What%20We%27re%20Making.md) · [2 ARD](02%20ARD%20-%20How%20the%20Pieces%20Fit.md) · [3 Checklist](03%20Prep%20Checklist.md) · [4 Handoff](04%20Build%20Handoff.md) · [5 Tests](05%20Tests%20and%20Decisions.md) · [6 Two ways](06%20Two%20Ways%20to%20Build%20It.md)

These are the **instructions** for the AI that writes the code. **Use them again** for the next change.

> [!NOTE]
> 1. 🧪 We make a DIGI 230 **prototype**. It is not a real product.
> 2. 📖 Read our [PRD](01%20PRD%20-%20What%20We%27re%20Making.md) and [ARD](02%20ARD%20-%20How%20the%20Pieces%20Fit.md).
> 3. ❓ Tell us about problems, missing decisions, and rules that you cannot enforce. **Ask before you code.**
> 4. 🎯 **Build only this:** a student reads a hint. The student decides Makes sense / Not sure / I disagree, with a reason. The student fixes the proof alone.
> 5. 🛠️ **Tools:** 1 HTML file. Plain JavaScript. Made-up proofs. **Labeled pretend hints.**
> 6. 🚫 **Do not** connect a real AI, add logins, track people, or add features **without asking**.
> 7. 📏 **Keep these rules:** no steps, no answers, no "correct", no grades. 2 steps first. 1 hint at a time. Unsure hints go to the teacher. A no-AI rule list. A stop button. Start over clears everything.
> 8. 📋 Show the files and commands first. Give setup steps and test steps. Say which tests ran.
> 9. ✋ **Then stop.** We check it.
